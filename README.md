## 📖 &nbsp; Project Overview

<img align="right" src="https://capsule-render.vercel.app/api?type=rect&height=200&width=340&color=gradient&customColorList=0,2,2,5,30&text=🚗%20SMVMS&fontSize=38&fontColor=ffffff&desc=IoT%20%7C%20AI%20%7C%20Edge%20Computing&descSize=15&descColor=a0e4ff&animation=fadeIn" width="340" alt="SMVMS Platform"/>

The **Smart Modular Vehicle Monitoring System (SMVMS)** is a next-generation vehicle intelligence platform that unifies:

- 🔧 **OBD-II Diagnostics** — Live engine & vehicle data streaming  
- 🎙️ **Acoustic Intelligence** — Sound-signature fault detection  
- 😊 **Driver Behaviour AI** — Facial & behavioral risk analysis  
- 🌿 **Eco-Drive Optimization** — Fuel & emission intelligence  
- 🔮 **Digital Twin Simulation** — Virtual vehicle fault prediction  

Each module operates **independently** yet integrates seamlessly into a unified edge-to-cloud platform — delivering real-time insights, predictive maintenance, and driver safety in a single system.

> 📍 **Institute:** Sri Lanka Institute of Information Technology (SLIIT)  
> 📘 **Module:** IT4010 — Research Project | 25 July Batch

## 🚀 &nbsp; Getting Started

</div>

### Prerequisites

```bash
# Ensure you have the following installed
Python >= 3.10
Node.js >= 18.x
npm >= 9.x
```

### Installation

```bash
# 1️⃣  Clone the repository
git clone https://github.com/<your-username>/smart-modular-vehicle-monitoring-system.git
cd smart-modular-vehicle-monitoring-system

# 2️⃣  Backend setup (Python)
cd backend
pip install -r requirements.txt
cp .env.example .env        # Configure environment variables

# 3️⃣  Frontend setup (React)
cd ../frontend/web
npm install

# 4️⃣  Run the backend server
cd ../../backend
python app.py               # or: uvicorn main:app --reload

# 5️⃣  Run the frontend
cd ../frontend/web
npm start
```

### Running on Raspberry Pi (Edge Device)

```bash
# Install edge dependencies
cd hardware/raspberry_pi
pip install -r requirements_edge.txt

# Launch all sensor modules
python main_edge.py --modules all
```
